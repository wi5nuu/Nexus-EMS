# Security Policy

## Supported Versions

The following versions of Nexus EMS are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes              |
| < 1.0.x | ❌ No               |

## Reporting a Vulnerability

We take the security of Nexus EMS seriously. If you believe you have found a security vulnerability in this project, please report it to us immediately.

### 🔍 How to Report
Please **do not** report security vulnerabilities via public GitHub issues. Instead, send a detailed report to **wisnu.dev@nexus.co** (or your primary contact email).

Your report should include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact of the vulnerability.
- Any suggested fix (if available).

### 🛡️ Response Time
You can expect a response within **48-72 hours**. We will investigate the issue and provide a timeline for the fix.

### 🎁 Disclosure Policy
Once the vulnerability is fixed, we will publish a security advisory. We ask that you do not disclose the vulnerability publicly until a fix has been released.
